# Dikshita Chalke — Portfolio

A responsive personal portfolio with the original cream/blue editorial direction, one real full-colour hero photo, a visible blue-and-white checkerboard, and a thread-connected scrapbook trajectory.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in Chrome.
3. Keep the `styles.css`, `script.js`, `public/`, and `dikshita-resume.pdf` files in their existing locations.

The site uses Google Fonts when connected to the internet; fallback fonts are included. The navigation works on mobile. Project copy avoids inventing performance results or claiming the research is complete.
